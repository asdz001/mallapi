📘 용어 해설 및 실전 예시

  • 🧠 CPU 사용률
    (서버가 얼마나 열심히 일하고 있는가)
    서버가 프로그램이나 작업을 처리하는 ‘두뇌’ 역할입니다.
    → 예: 상품 수집이나 주문 전송 시 CPU가 순간적으로 높아질 수 있음.
    → 85% 이상이 장시간 지속되면 과부하로 서버가 느려질 수 있음.

  • 💾 메모리 (RAM)
    (작업을 빠르게 처리하기 위한 임시 저장 공간)
    서버가 파일을 읽거나 이미지를 가공할 때, 실행 중인 프로그램이 사용하는 공간입니다.
    → 예: 상품 이미지 500장을 다운로드하거나, 대량 데이터를 정제할 때 많이 사용됩니다.
    → RAM이 부족하면 스왑으로 넘어가고, 속도가 급격히 느려집니다.

  • 🪫 스왑 메모리 (SWAP)
    (RAM이 부족할 때 디스크를 임시로 메모리처럼 사용하는 공간)
    속도가 느리기 때문에 사용량이 많을수록 성능 저하가 발생합니다.
    → 예: 메모리가 2GB인데 이미지 수집 작업이 4GB 메모리를 요구할 때 스왑이 사용됨
    → 스왑이 1GB 이상이면 서버가 무겁게 느려지기 시작합니다.

  • 📦 디스크 사용량
    (하드디스크 공간, 로그/이미지/데이터 저장소)
    서버의 파일, 로그, DB 백업, 이미지 등이 저장되는 공간입니다.
    → 예: 상품 이미지 수집, 로그 저장, DB 덤프 백업 등이 디스크를 채웁니다.
    → 90% 이상이면 저장 실패 가능성 있음 (DB 저장 불가, 오류 발생 등)

  • 📉 Load Average
    (서버가 동시에 처리하려는 작업 수의 평균)
    1/5/15분 간 CPU에 몰린 요청의 수치를 나타냅니다. 숫자가 코어 수보다 크면 병목이 발생합니다.
    → 예: 1코어 서버에서 load average가 3이라면 3배 과부하 상태

  • 🌐 네트워크 트래픽
    (서버가 인터넷으로 데이터를 주고받는 속도)
    이미지 다운로드, API 요청, 주문 전송 등 모든 통신이 네트워크에 포함됩니다.
    → 예: 이미지 대량 수집 시 수신 속도 증가 / 주문 전송 시 송신 속도 증가
    → 갑작스레 트래픽이 많아지면 외부 API가 차단되거나 속도가 느려질 수 있습니다.
